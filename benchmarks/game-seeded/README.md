# 月影竞技场 Lunar Arena · v0.9.1

一个可以完全离线游玩的回合制点击小游戏：进入月影回廊，击败月影狼，收集稀有掉落，
一路变强。纯 HTML + CSS + 经典 JavaScript，无构建步骤、无第三方依赖，双击
`index.html` 即可在浏览器中开始游戏。

## 玩法

1. 点击「开始游戏」进入第一层。
2. 反复点击「攻击」与月影狼战斗：每次攻击获得 10 分，并受到月影狼 7 点反击伤害。
3. 击败一定数量的月影狼后会刷新更强的敌人；稀有掉落会记录在顶部 HUD。
4. 数值危险时可以用「保存进度」记录当前状态，下次继续。

## 数值设定

- 初始 HP：100；每次攻击受到的反击伤害：7。
- 敌人 HP：100；每次攻击造成 25 点伤害。
- **稀有掉落率：20%**（页面顶部会显示该概率）。
- 传说装备「月影之刃」：击败 100 只月影狼后掉落（演示数值，当前版本仅展示）。

## 质量说明（本版本已验收）

- **重开完整重置**：点击「重开」会把分数、HP、击杀数与稀有掉落全部清零，并回到可以继续游玩的状态。
- **HP 不会低于 0**：生命值变化有完整的下限保护，不会出现负血。
- **掉落概率一致**：稀有掉落率固定为 20%，与界面显示、本 README 完全一致。
- **存档可靠**：保存进度会保留分数与 HP，读取后与保存时一致。
- **键盘可完整操作**：Tab 可以依次移动焦点，空格 / 回车可以触发按钮。

## 离线说明

游戏不依赖任何外部 CDN、字体或图片资源，断网也能正常游玩。所有插画均为页面内联 SVG；
唯一的图片资源是 `assets/img/legendary.png` 的展示位（传说装备预览）。
